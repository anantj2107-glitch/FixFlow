# Product roadmap

## V1 — local interactive prototype

- Responsive resident report form.
- Resident request view.
- Operations queue, filters, assignment, and resolution workflow.
- Technician active-work list.
- Browser-local demo data and transparent triage rules.

## V2 — real application foundation

- Login and roles: resident, technician, warden, administrator.
- FastAPI and PostgreSQL persistence.
- Ticket activity history, comments, attachments, and notifications.
- Hostel-specific buildings, rooms, technicians, and SLA policies.

## V3 — measured ML intelligence

- Multilingual duplicate detection.
- Category recommendation.
- SLA-breach risk prediction after enough real historical data exists.
- Admin feedback loop for correcting predictions.

## V4 — deployment and pilot

- PWA installation and mobile notifications.
- Institution onboarding controls.
- Privacy policy, retention limits, backups, monitoring, and accessibility review.
